View Release →
Security

🔐 Secure Token Rotation & Big-File Stability

QR bootstrap tokens now auto-rotate every ~4.5 minutes and the desktop QR updates live. Active transfers defer rotation via activeUploads watchdog guard (beamsync/server.go:600). Download tokens extended to 30 min (was 5) — large files no longer fail mid-queue. Mobile heartbeat no longer kills a mid-download on 401/403.

Mobile

📱 Complete Mobile UI Overhaul

Radically redesigned mobile web UI with a structured layout — clear lanes for queued, uploading, and completed files.

UX

✨ Intelligent File Lists

Selected desktop files cascade in a staggered entrance animation. Mobile download view populates a dedicated DOWNLOADED FILES section live as downloads complete.

Design

🎨 Rich Iconography

Dynamic, color-coded SVG icons for dozens of types — code, video, images, scripts, text, archives and more. Instant visual scanning.

Reliability

📄 X-Filename Header Fix

Backend now passes and respects the X-Filename HTTP header so the original filename is preserved correctly on every transfer — no more truncated or mangled names.

Accessibility

♿ prefers-reduced-motion

All animated elements — staggered lists, progress, carousel and waves — fully respect prefers-reduced-motion for inclusive motion handling.
