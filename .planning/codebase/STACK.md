# Technology Stack

**Analysis Date:** 2026-07-20

## Languages

**Primary:**
- Go 1.25.5 - Core transfer engine (`beamsync/`) and desktop app (`desktop/`)

**Secondary:**
- JavaScript (ES modules) - Wails desktop frontend (`desktop/frontend/src/`) and community site (`community/src/`)
- HTML/CSS - Embedded upload/download web UIs (`beamsync/ui/`)
- Shell (Bash) - Build scripts, firewall setup, CI steps

## Runtime

**Environment:**
- Go compiled binary — no separate runtime required for end users
- Wails v2.12.0 embeds a native webview (WebView2 on Windows, WKWebView on macOS, webkitgtk on Linux)

**Package Manager:**
- Go modules (`go.mod`) for Go dependencies
- npm for frontend dependencies
- Lockfiles: `go.sum` (both modules), `package-lock.json` (desktop/frontend, community)

## Frameworks

**Desktop:**
- [Wails v2.12.0](https://github.com/wailsapp/wails/v2) - Go-native cross-platform desktop framework; uses embedded webview for UI rendering
  - Config: `desktop/wails.json`
  - Backend bindings via `go/main/App.js` (auto-generated by Wails)

**Frontend:**
- [Svelte 3.x](https://svelte.dev) - Desktop UI components (`desktop/frontend/src/`)
  - Plugin: `@sveltejs/vite-plugin-svelte@^1.0.1`
- [Vite 3.x](https://vitejs.dev) - Build tool for frontend assets
  - Config: `desktop/frontend/vite.config.js`
- [Astro 5.x](https://astro.build) - Community/landing site
  - Config: `community/astro.config.mjs`

**Audio:**
- [faiface/beep v1.1.0](https://github.com/faiface/beep) - Sound playback for UI feedback (connect, transfer-complete, click, etc.)
  - Backend audio driver: `hajimehoshi/oto v0.7.1`
  - Sample rate: 44100 Hz, WAV format embedded via `//go:embed`

**Testing:**
- Go standard `testing` package - Unit tests for core library
  - Test files co-located: `*_test.go` alongside source
  - No external test framework

**Build/Dev:**
- Wails CLI (`wails build`) - Cross-platform desktop builds (Linux amd64, Windows amd64)
- Vite dev server - Frontend hot-reload during development
- `gofmt` - Format enforcement (checked in CI)
- `go vet` - Static analysis (checked in CI)
- Astro CLI - Community site build

## Key Dependencies

**Critical:**
- `github.com/wailsapp/wails/v2 v2.12.0` - Desktop wrapper providing native window, webview, filesystem dialogs, runtime event system
- `github.com/faiface/beep v1.1.0` - Audio playback for desktop sound effects
- `qrcode@^1.5.4` - QR code generation in the Svelte frontend for mobile pairing

**Infrastructure:**
- `github.com/google/uuid v1.6.0` - UUID generation (transitive via Wails)
- `github.com/gorilla/websocket v1.5.3` - WebSocket support (transitive via Wails)
- `github.com/labstack/echo/v4 v4.13.3` - HTTP router (transitive via Wails)
- `github.com/wailsapp/go-webview2 v1.0.22` - Windows WebView2 integration

## Configuration

**Environment:**
- `BEAMSYNC_ENABLE_TLS` (optional) - Set to `"1"`, `"true"`, `"yes"`, or `"on"` to enable HTTPS with a self-signed certificate
  - Checked in `beamsync/tls.go`

**Local Config File:**
- `~/.config/beamsync/config.json` - Persistent user preferences (save path, transfer settings)
  - Written by `desktop/app.go` via `saveConfig()`

**TLS Certificates (optional):**
- `~/.config/beamsync/cert.pem` - Self-signed TLS certificate
- `~/.config/beamsync/key.pem` - ECDSA P-256 private key
- Auto-generated on first use when TLS is enabled

**Build:**
- `desktop/wails.json` - Wails project configuration (app name, version, build settings)
- `desktop/wailsjs/runtime/package.json` - Wails auto-generated JS runtime

## Platform Requirements

**Development:**
- Go 1.25.5+
- Node.js (latest LTS, currently v24 for CI)
- libasound2-dev (Linux, for audio backend)
- Optional: x86_64-w64-mingw32-gcc (for Windows cross-compilation on Linux)
- Optional: NSIS (for Windows installer builds)

**Production:**
- Linux: WebKitGTK (webkit2gtk-4.0), libayatana-appindicator3, GTK3
- Windows: WebView2 runtime (auto-installed if missing by NSIS installer)
- macOS: WKWebView (built-in, no additional deps)
- AUR package available: `beamsync-bin` (`.aur/beamsync-bin/`)
