### Task 1.2.2 — Unify version to wails.json

<read_first>
- desktop/app.go
- desktop/wails.json
</read_first>

Replace hardcoded `const currentVersion` with embed+parse of `wails.json`.

Steps:
1. Add `//go:embed wails.json` and `var wailsJSONData []byte` at package level in `app.go`
2. Add `version string` field to `App` struct
3. Add `const fallbackVersion = "v2.4.0"` for JSON parse failure
4. At the top of `startup()`, parse wailsJSONData:
   ```go
   type wailsInfo struct {
       Info struct {
           ProductVersion string `json:"productVersion"`
       } `json:"info"`
   }
   var info wailsInfo
   if err := json.Unmarshal(wailsJSONData, &info); err != nil {
       fmt.Println("⚠️ Failed to parse wails.json:", err)
       a.version = fallbackVersion
   } else {
       a.version = "v" + info.Info.ProductVersion
   }
   ```
5. Remove `const currentVersion = "v2.4.0"` (line 29)
6. Add `func (a *App) GetVersion() string { return a.version }`
7. Update `CheckForUpdate()` — replace all 4 references to `currentVersion` with `a.version`

<acceptance_criteria>
- `const currentVersion` removed from `app.go`
- `GetVersion() string` method returns `"v2.4.0"` (from parsed wails.json)
- `CheckForUpdate()` compiles with `a.version` instead of `currentVersion`
- `go build ./...` passes in `desktop/` module
</acceptance_criteria>

<verification>
- `grep -n 'currentVersion' desktop/app.go` returns zero matches
- `(cd desktop && go build ./... && go vet ./...)` passes
</verification>
