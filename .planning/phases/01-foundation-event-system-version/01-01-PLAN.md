<action>
Per D-02 (CONTEXT.md): Log-only drop exposure. `DroppedCount()` on dispatcher for testing. No Wails-bound method.

1. Add `"sync/atomic"` to the import block in `beamsync/server.go`.
2. Add `dropped atomic.Int64` field to the `eventDispatcher` struct (line 39-41). The struct becomes:
   ```go
   type eventDispatcher struct {
       queue   chan eventDispatchJob
       dropped atomic.Int64
   }
   ```
3. In the `emit()` method (line 69-79), on the `default:` branch, increment `d.dropped.Add(1)` BEFORE `return false`. The complete default branch:
   ```go
   default:
       d.dropped.Add(1)
       return false
   ```
4. Add a `DroppedCount()` method after `emit()`:
   ```go
   func (d *eventDispatcher) DroppedCount() int64 {
       return d.dropped.Load()
   }
   ```
5. In the `run()` method (line 54-67), at the end of the for loop (after the callback executes, before the next iteration), log if drops are non-zero using the existing fmt.Printf pattern:
   ```go
   if count := d.dropped.Load(); count > 0 {
       fmt.Printf("Event dispatcher: %d events dropped\n", count)
   }
   ```
   This logs once per batch after a drop event, avoiding per-iteration log spam.

IMPORTANT: Do NOT add a `GetDropped()` or similar Wails-bound method — the decision is to keep this internal/testing-only per D-02.

IMPORTANT: Do NOT create a separate file or wrapper type. All changes stay in `server.go` within the existing `eventDispatcher` type.
</action>
