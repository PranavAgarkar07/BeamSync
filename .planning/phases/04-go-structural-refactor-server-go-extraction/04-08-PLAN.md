Move the `/download` and `/download/N` handler bodies into a single method on `*HTTPServer`, `handleDownload`, in the new focused file `beamsync/download_handler.go`. No behavior change.

Purpose: Eighth step in the risk-ascending sequence (CONTEXT D-07); the second handler-body extraction converts captured-closure handlers into methods, and the two bodies are behaviorally identical apart from the base-name variable (CONTEXT D-12), so one implementation serves both.
